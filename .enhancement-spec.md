# NileShop Enhancement Spec — Shared Contracts

## API Contracts (Backend ↔ Frontend)

### AJAX Add to Cart
- **Endpoint:** `POST /Cart/AddAjax`
- **Request:** Form data: `productId` (int), `quantity` (int), `selectedSize` (string?), `selectedColor` (string?), `__RequestVerificationToken`
- **Success response (200):** `{ "success": true, "cartCount": 5, "message": "Added to cart" }`
- **Failure response (400):** `{ "success": false, "message": "Out of stock" }`

### Mini Cart Data
- **Endpoint:** `GET /Cart/MiniCart`
- **Response (200):**
```json
{
  "items": [
    { "name": "Everyday knit runner", "image": "/assets/img/products/everyday-runner.jpg", "price": 1299.00, "quantity": 2, "size": "42", "color": "Black", "lineTotal": 2598.00 }
  ],
  "count": 3,
  "total": 3897.00
}
```

### Rating Data (ViewBag)
- `ViewBag.Ratings` = `Dictionary<int, (double Average, int Count)>` — keyed by ProductId, only approved reviews
- Set in HomeController.Index, HomeController.Shop, ProductsController.Details

### Bestseller IDs (ViewBag)
- `ViewBag.BestsellerIds` = `HashSet<int>` — top 3 ProductIds by total OrderItem quantity sold
- Set in HomeController.Index, HomeController.Shop

### SEO ViewData (set by ProductsController.Details)
- `ViewData["og:title"]` = product localized name
- `ViewData["og:description"]` = product localized short description
- `ViewData["og:image"]` = absolute URL to product main image
- `ViewData["og:type"]` = "product"
- `ViewData["og:price"]` = product price as string
- `ViewData["JsonLd"]` = serialized JSON-LD string for Product schema

## CSS Class Conventions

All new styles go in a NEW file: `wwwroot/assets/css/enhancements.css`

### Toast Notification
```
.toast-container          — fixed bottom-right, z-index 9999, pointer-events none
.toast-notification       — card, slides in from right, 3s auto-dismiss
.toast-notification.show  — visible state (transform: translateX(0))
.toast-icon               — checkmark or X icon
.toast-message            — text content
```

### Mini-Cart Drawer
```
.mini-cart-overlay         — fixed fullscreen, semi-transparent backdrop, z-index 1000
.mini-cart-overlay.open    — visible (opacity 1, pointer-events auto)
.mini-cart-drawer          — fixed right, full-height, ~380px wide, slides from right
.mini-cart-drawer.open     — visible (transform: translateX(0))
```

## JavaScript Function Specs

### Toast System
```js
function showToast(message, type = 'success') // type: 'success' | 'error'
// Creates toast element, appends to container, auto-removes after 3s
```

### AJAX Add to Cart
```js
// Intercept all add-to-cart forms with data-ajax-cart attribute
// POST to /Cart/AddAjax with form data
// On success: showToast(response.message), update cart count badge, refresh mini-cart
// On error: showToast(response.message, 'error')
```

### Mini-Cart
```js
function openMiniCart() // Fetches /Cart/MiniCart, populates drawer, shows overlay
function closeMiniCart() // Hides overlay and drawer
// Cart icon click → openMiniCart()
// Overlay click or close button → closeMiniCart()
// Escape key → closeMiniCart()
```

### Dark Mode
```js
// On load: check localStorage 'darkMode' or prefers-color-scheme
// Toggle: add/remove 'dark-mode' class on <html>, save to localStorage
// Header button click → toggle
```

### Recently Viewed
```js
// On product detail page: save product { id, name, slug, image, price } to localStorage 'recentlyViewed' (max 8, FIFO)
// On home/shop page: read from localStorage, render section if any items exist
```

### Scroll Animations
```js
// IntersectionObserver on all .animate-on-scroll elements
// When intersecting (threshold 0.1): add .visible class
// Once visible, unobserve (animate once only)
```

### Cookie Consent
```js
// On load: check localStorage 'cookieConsent'
// If not set: show .cookie-consent bar
// Accept click: set localStorage, hide bar
```

### Checkout Spinner
```js
// On checkout form submit: show .checkout-overlay, disable submit button
// Prevent double-submission
```
